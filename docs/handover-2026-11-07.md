   ```bash

     CRAWL4AI_NO_CLOUD_NOTICE=1 CRAWL4AI_CDP_URL=http://127.0.0.1:9333 \
     $PY scripts/search/reader_eval.py model --backend $b --key-file ../qqbot-data/tools/deepseek.key \
         --out ../qqbot-data/runs/search/model.$b.json
   ```

## 6. 已知的坑

- 本容器和 <HK_HOST> 都是机房 IP：萌娘百科、百度百科、知乎 403；B 站 `api` 对伪装浏览器且不带 cookie 的请求返回 412（BVR 的非浏览器 UA 反而能拿到元数据）。

- 读 `~/.dsh` 下的凭据文件会被 Claude 的权限规则拦截；dsh 自己读不受影响。
- 打标页等含原名的文件经 dsh 发给用户时，先复制到仓库内被 git 忽略的 `tmp/`，再用 `dsh-artifact:tmp/...` 链接。
